농업기술센터 로컬 업무자동화 포털 (오프라인 전용) 사용 설명서
외부 전송 없는 PC 내부 전용 행정 업무처리 시스템

1. 시스템 개요
--------------------------------------------------------------------------------
본 시스템은 농촌진흥청 산하 시·군 농업기술센터의 농촌지도사, 농업직, 행정직 공무원이
현장에서 반복적으로 수행하는 데이터를 간편하고 빠르게 자동 처리하는 '완전 로컬형' 업무 포털입니다.

★ 핵심 보안 원칙:
- 인터넷 연결이 전혀 없는 폐쇄망/행정망 PC에서도 100% 정상 작동합니다.
- AI, LLM, 클라우드 API, 외부 CDN, 외부 웹폰트를 일절 사용하지 않습니다.
- 모든 파일과 데이터는 현재 PC 브라우저 메모리 안에서만 처리되며, 외부 서버로 일절 전송되지 않습니다.
- 프로그램 종료 또는 브라우저 새로고침 시 작업 중인 데이터는 메모리에서 즉시 소멸되어 안전합니다.


2. 프로그램 실행 방법 (2가지 버전)
--------------------------------------------------------------------------------
【버전 A : 완전 정적 웹 버전 (가장 추천 - 설치 불필요)】
1) '농업기술센터_업무자동화' 폴더를 열고 `index.html` 파일을 더블클릭합니다.
2) Chrome 또는 Microsoft Edge 브라우저에서 포털 화면이 즉시 열립니다.
   (별도의 프로그램 설치나 관리자 권한이 전혀 필요 없습니다)
※ 폴더 내의 `포털실행.bat`을 더블클릭하셔도 기본 브라우저로 바로 실행됩니다.

【버전 B : 단독 윈도우 앱 버전 (Python WebView 런처)】
1) Python 환경이 갖춰진 PC에서는 `launcher.py`를 실행하여 독립 윈도우 창으로 사용할 수 있습니다.
2) 단독 실행파일(exe)로 변환을 원하실 경우:
   `pip install pywebview pyinstaller`
   `pyinstaller -w -F --add-data "assets;assets" --add-data "sample;sample" --add-data "index.html;." launcher.py`
   명령을 통해 단독 실행용 exe 파일로 패키징할 수 있습니다.


3. 주요 30가지 기능 안내
--------------------------------------------------------------------------------
[데이터 통합 및 기초 정리]
01. 엑셀/CSV 파일 통합 : 여러 읍·면 또는 담당자별 CSV 파일을 하나로 합치고 출처 기록 및 중복 제거
02. 농가 명단 정리     : 공백 제거, 전화번호(010-XXXX-XXXX) 통일, 고유번호 생성, 가나다순 정렬
03. 중복·누락 데이터 검사 : 전화번호/주소 중복, 필수 항목 누락, 형식 오류를 색상으로 식별
15. CSV 변환 및 추출   : 탭(TSV)·세미콜론 변환, 엑셀 호환 UTF-8 BOM 변환, 특정 컬럼 선택 추출

[농가 및 교육생 관리]
04. 교육생 명단 관리   : 교육 신청자 수, 성별, 소속읍면, 과정별 통계 및 명찰용 데이터 추출
05. 출석부 생성 (A4)   : 교육명, 일시, 장소를 입력하고 서명란이 포함된 A4 규격 출석부 자동 생성 및 인쇄
16. 문자 발송용 명단 생성 : 010 번호 정규화, 중복 번호 자동 제거, 단체문자 시스템 업로드용 CSV 생성
17. 주소·전화번호 정리 : 연속 공백 제거, 지번/도로명 정돈, 유효하지 않은 번호 사전 검출

[사업·현장·출장 기록]
06. 만족도 조사 집계   : 문항별 평균, 최고/최저점, 긍정 응답률(%), Canvas 순수 차트 및 보고서 출력
07. 시범사업 신청자 정리 : 재배면적, 청년농 여부 등 사용자 정의 배점 규칙 기반 우선순위 산정
08. 사업실적 집계     : 총사업비(국비/지방비/자부담) 집계 및 사업 완료율(%) 자동 산출
09. 현장조사 데이터 정리 : 영농 현장지도 및 병해충 예찰 데이터를 담당자/품목별로 다차원 필터링
10. 출장기록 작성 (복명서) : 출장목적, 확인사항, 지도내용을 관공서 표준 출장복명서 서식으로 즉시 인쇄/PDF 저장

[파일 및 사진 도구]
11. 사진 파일명 일괄 변경 : 스마트폰 사진들을 [날짜_품목_업무_농가명_연번.jpg]로 일괄 변경 후 ZIP 다운로드
12. 사진 업무별 분류   : 사업전, 사업후, 교육, 현장지도 등 행정 목적별로 태그를 붙여 ZIP 다운로드
13. 파일 일괄 이름 변경 : 접두어, 접미어, 문자열 치환, 연번 부여 후 일괄 압축 다운로드
14. 폴더 파일목록 대장 : 폴더 전체를 선택하여 파일명, 확장자, 크기, 수정일시 엑셀(CSV) 대장 생성

[통계 및 보고서 생성]
18. 농가별 통계       : 농가별 총 수혜금액, 참여사업 수, 재배면적 합계 및 평균 집계
19. 읍면별 통계       : 관내 11개 읍·면별 농가 분포, 총 면적, 사업비 비교 차트 및 집계표
20. 월간/분기 실적 집계 : 날짜 데이터를 기반으로 월별(1~12월), 분기별, 반기별 실적 피벗 집계
21. 보고서용 표 생성   : 합계행 및 천단위 콤마가 적용된 공문서 표를 '한글(HWP)'에 바로 붙여넣기
22. 업무 체크리스트   : 시범사업 심사, 현장점검, 교육 준비 체크리스트 작성 및 브라우저 보관

[데이터 가공 및 유틸리티]
23. 데이터 비교 (Diff) : 이전 명단 vs 올해 명단 비교 (신규, 삭제, 변경, 동일 행 색상별 구분)
24. 데이터 필터링     : 복수 조건(AND) 결합 조건식 필터링
25. 데이터 정렬       : 1차 기준(읍면) 및 2차 기준(성명/사업비) 다중 정렬
26. 텍스트 일괄 치환   : CSV 내의 오탈자나 명칭 일괄 찾기/바꾸기
27. 날짜 형식 통일     : 혼재된 날짜 표기를 YYYY-MM-DD 표준 형식으로 통일
28. 개인정보 마스킹   : 성명(홍*동), 전화번호(010-****-5678), 주소 비식별화 파일 별도 생성
29. QR용 코드 생성     : 100% 오프라인 Canvas를 활용한 교육 등록 및 안내용 QR 코드 생성/인쇄
30. 사용자 설정       : 소속 기관명(○○군 농업기술센터), 부서명, 담당자 기본값, 테마 설정


4. 샘플 데이터 활용 안내
--------------------------------------------------------------------------------
`sample/` 폴더에 테스트용 가상 데이터가 준비되어 있습니다:
- 농가명단_샘플.csv (120행) : 농가명단 정리, 중복누락 검사, 시범사업 신청자 정리 테스트용
- 교육생명단_샘플.csv (120행) : 교육생 관리, 출석부 생성, 문자발송 명단 생성 테스트용
- 사업실적_샘플.csv (220행) : 사업실적 집계, 농가별/읍면별 통계, 기간별 피벗 집계 테스트용
- 만족도조사_샘플.csv (100행) : 만족도 통계 및 Canvas 차트 테스트용
- 현장조사_샘플.csv (60행)  : 현장조사 데이터 정리 및 필터링 테스트용
- A읍/B면/C면 농가명단.csv   : 엑셀/CSV 파일 통합(Merge) 기능 테스트용


5. 한글 인코딩 깨짐 방지 기술 안내
--------------------------------------------------------------------------------
- 행정망 및 한글 엑셀에서 내보낸 CSV 파일은 대부분 `CP949/EUC-KR` 또는 `UTF-8`입니다.
- 본 포털은 파일 바이트를 직접 검사하여 인코딩을 자동으로 감지하므로 한글이 깨지지 않습니다.
- 포털에서 처리 후 내려받는 모든 CSV 파일은 `UTF-8 BOM`이 자동으로 부착되어 있어,
  일반 사용자 PC의 엑셀에서 더블클릭하여 열어도 한글이 완벽하게 정상 표시됩니다.
