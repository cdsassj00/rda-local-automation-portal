# 농업기술센터 로컬 업무자동화 포털 (RDA Local Automation Portal)

> **외부 전송 없는 PC 내부 전용 행정 업무처리 시스템**  
> 농촌진흥청 산하 시·군 농업기술센터 공무원(농촌지도사·농업직·행정직)을 위한 완전 로컬형 업무자동화 포털

---

## 🌟 핵심 특징

1. **100% 로컬 오프라인 작동**: 외부 클라우드, 외부 API 호출, 외부 CDN을 전면 배제하여 인터넷이 차단된 행정망에서도 완벽하게 작동합니다.
2. **개인정보 및 사업데이터 철저 보호**: 농가 개인정보, 전화번호, 경영체 등록번호 등이 PC 외부로 절대 전송되지 않습니다.
3. **초고속 원클릭 실행 (2가지 배포 옵션)**:
   - **옵션 A (단일 파일)**: `농업기술센터_업무자동화_단일포털.html` 파일 1개만 더블클릭하면 0.1초 만에 실행 (파이썬/설치 불필요)
   - **옵션 B (원클릭 설치 패키지)**: `[1]설치하기_원클릭.bat` 실행 시 바탕화면 바로가기 생성 및 faster-whisper, EasyOCR 고기능 자동 연동
4. **한글 엑셀(CSV) 인코딩 자동 보정**: `CP949/EUC-KR` 및 `UTF-8`을 자동 판별하여 한글 깨짐을 원천 차단하며, 다운로드 시 `UTF-8 BOM`을 자동 부착합니다.

## 🚀 빠른 시작 가이드

### 방법 1: 단일 HTML 파일로 즉시 실행 (가장 추천)
* `농업기술센터_업무자동화_단일포털.html` 파일을 더블클릭합니다.
* Chrome, Microsoft Edge 등 모든 웹 브라우저에서 즉시 실행됩니다.

### 방법 2: 바탕화면 바로가기 및 고기능 AI 설치
1. `[1]설치하기_원클릭.bat`을 더블클릭합니다.
2. 윈도우 바탕화면에 **[농업기술센터 업무포털]** 바로가기 아이콘이 자동 생성됩니다.
3. 바탕화면 아이콘을 클릭하면 로컬 AI 엔진(faster-whisper, EasyOCR)과 포털이 함께 실행됩니다.

## 📋 제공 기능 (총 32개 메뉴)

### 🧠 로컬 고기능 AI 엔진 (오프라인)
- **31. 현장 음성녹음 전사 (faster-whisper STT)**: 스마트폰 녹음 파일(`m4a`, `mp3`, `wav`)을 100% 로컬에서 전사하여 출장복명서로 자동 변환
- **32. 서류·영수증 문자 인식 (EasyOCR)**: 종이 농지원부, 영농자재 영수증 사진을 문자 인식하여 텍스트 및 CSV 표로 자동 추출

### 📊 데이터 통합·정리
- **01. 엑셀/CSV 파일 통합**: 여러 읍·면/담당자별 CSV 파일 다중 선택 병합 및 중복 제거
- **02. 농가 명단 정리**: 공백 제거, 전화번호(010-XXXX-XXXX) 정규화, 고유번호 생성, 가나다순 정렬
- **03. 중복·누락 데이터 검사**: 필수값 누락, 연락처 중복, 형식 오류 색상별 자동 식별 및 리포트 다운로드

### 👥 농가·교육생 관리
- **04. 교육생 명단 관리**: 교육 신청자 수, 소속 읍면/과정별 통계 및 명찰용 데이터 추출
- **05. 출석부 생성 (A4)**: 교육명, 일시, 장소 입력 후 서명란이 포함된 관공서 표준 출석부 생성 및 A4 인쇄/PDF 저장
- **16. 문자 발송용 명단 생성**: 010 표준화, 중복 번호 자동 제거, 단체문자 대량발송 전용 CSV 생성
- **17. 주소·전화번호 정리**: 연속 공백 제거, 지번/도로명 정돈, 비유효 번호 필터링

### 📋 사업·현장·출장
- **06. 만족도 조사 집계**: 문항별 평균, 최고/최저점, 긍정 응답률(%) 산출 및 순수 Canvas 차트/보고서 출력
- **07. 시범사업 신청자 정리**: 재배면적, 청년농 여부 등 사용자 정의 배점 규칙 기반 우선 검토 순위 자동 산정
- **08. 사업실적 집계**: 총 사업비(국비/지방비/자부담) 집계 및 사업 완료율(%) 자동 산출
- **09. 현장조사 데이터 정리**: 영농 지도 및 병해충 예찰 일지 다차원 필터링
- **10. 출장기록 작성 (복명서)**: 관공서 표준 출장복명서 서식 자동 배치 및 A4 인쇄

### 📁 파일·사진 도구
- **11. 사진 파일명 일괄 변경**: `[날짜_품목_업무_농가명_연번.jpg]` 규칙 일괄 부여 및 순수 JS ZIP 압축 다운로드
- **12. 사진 업무별 분류**: 사업전, 사업후, 교육, 병해충 등 업무별 태깅 및 압축 다운로드
- **13. 파일 일괄 이름 변경**: 접두어, 접미어 추가, 문자열 치환, 연번 부여
- **14. 폴더 파일목록 대장**: 폴더 내 파일명, 확장자, 크기(KB/MB), 수정일시 CSV 대장 생성
- **15. CSV 변환 및 추출**: 탭(TSV), 세미콜론(;) 변환, UTF-8 BOM 변환, 특정 컬럼 추출

### 📈 통계·보고서
- **18. 농가별 통계**: 농가별 총 수혜금액, 참여 사업 수, 교육 이수 횟수, 재배면적 집계
- **19. 읍면별 통계**: 관내 읍·면별 농가 분포, 면적, 사업비 비교 차트 및 집계표
- **20. 월간/분기 실적 집계**: 날짜 기반 월별(1~12월), 분기별, 반기별 실적 피벗 집계
- **21. 보고서용 표 생성**: '한글(HWP)'에 바로 붙여넣을 수 있는 공문서 규격 표 생성 (합계행, 천단위 콤마)
- **22. 업무 체크리스트**: 시범사업 심사, 현장점검, 교육 준비 체크리스트 작성 및 브라우저 보관

### ⚙️ 데이터 가공·비교·설정
- **23. 데이터 비교 (Diff)**: 이전 명단 vs 신규 명단 대조 (신규, 삭제, 변경, 동일 행 색상별 구분)
- **24. 데이터 필터링**: 복수 조건(AND) 결합 조건식 필터링
- **25. 데이터 정렬**: 다중 컬럼 오름차순/내림차순 정렬
- **26. 텍스트 일괄 치환**: 전체 또는 특정 컬럼에서 오탈자나 명칭 일괄 바꾸기
- **27. 날짜 형식 통일**: 혼재된 날짜를 `YYYY-MM-DD` 표준 형식으로 일괄 통일
- **28. 개인정보 마스킹**: 성명(홍*동), 전화번호(010-****-5678), 주소 비식별화 파일 별도 생성
- **29. QR용 텍스트/코드 생성**: 오프라인 순수 Canvas QR 엔진으로 교육 설문 및 안내용 QR 코드 생성
- **30. 사용자 설정**: 소속 기관명, 부서명, 담당자 기본값, 화면 테마(라이트/다크) 설정
